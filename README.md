# Scoop bucket for Wave Subs

```powershell
scoop bucket add wavesubs https://github.com/jason-jm/scoop-wavesubs
scoop install wavesubs
```

Wave Subs generates SRT/ASS subtitles from any video with local AI and auto-translates them. Windows 10+ x64, portable build.
Website: https://wavesubs.com · Source: https://github.com/jason-jm/wavesubs
